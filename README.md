# UI Automation Project – Selenium + Java

This project includes UI automation scripts using Selenium WebDriver and Java.

## Tools & Technologies

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Jenkins (optional)

## Features Covered

- Login page test
- Invalid credentials test
- Home page validation
- Cross-browser readiness

## How to Run

1. Clone the repo or download it
2. Use Maven to install dependencies
3. Run with TestNG or your IDE
